Queue changes
- One process-shared FIFO journal and one STA CAD executor per Windows user and
  desktop session. The ownership mutex is independent of release and state path.
- The protected unit includes the whole submitted CAD plan, rebuild, supported
  rollback, validation and save/export. Separate tool calls are separate units.
- Durable request IDs and get_queue_request support result lookup after a lost
  response without replaying a completed or uncertain mutation.
- Timeouts and interrupted execution retain a recovery fence. They do not kill
  CAD, release a still-active operation, or imply that an outstanding COM call
  stopped. Recovery requires recorded return evidence or proof that the original
  CAD process generation ended, followed by explicit operator acknowledgement.
- Activation binds an explicit PID, process generation and expected major 33.
  It refuses legacy clients or a live broker and never deletes the journal or
  clears its recovery state. Status/polling do not read the model through COM.
- Native state is canonical and private:
  %LOCALAPPDATA%\SolidworksMCP\coordination\v1\<sessionhash>
- Raw Python requires coordination.trusted_python=true. It must stay synchronous
  within the operation and must not spawn work or independently rebind COM.
  Static validation is not a sandbox. Prefer typed tools and CAD plans.
- Automatic UI dialog resolution and automatic recovery are disabled.

Delivery and validation boundaries
- scripts/prepare_queue_release.py builds a new directory from clean committed
  HEAD and writes a version/file-hash manifest. It does not activate or fetch LFS.
- scripts/switch_mcp_config.py defaults to dry-run. Explicit --apply is guarded
  by process inventory and the CAD lease, preserves foreign TOML bytes and file
  permissions, and creates a unique private exact-block backup. Restore requires
  the unchanged activated full-config hash; later user edits are not overwritten.
- Local unit, journal, independent-process and synthetic deployment tests are
  distinct from native CAD acceptance. See docs/QUEUE_OPERATIONS.md for the live
  acceptance matrix, cutover, recovery and rollback commands.
- Packaged line-art paths currently contain Git LFS pointers, not model blobs.
  Full line-art/CUDA readiness and other SOLIDWORKS versions are not qualified by
  queue tests or release preparation.
- The inherited initial README blob was recovered in the isolated repository
  from upstream after exact Git-object hash verification. Git integrity checks
  and a bounded history/private-path scan pass. The original installation's Git
  objects remain unchanged. Archives disable LFS smudging and retain pointers;
  unavailable model weights are not downloaded implicitly.
- MIT/upstream attribution is preserved. No public push or release is authorized
  by this staging work. See docs/GITHUB_READINESS.md before publication review.

HISTORICAL: SolidWorks MCP 6.5.31-local.1
Local reliability fixes for SOLIDWORKS 2025 SP2.0 (33.2.0), Russian templates.
Base: 38468b32890a9fc4c4aeec50fa97f679496c4524 (6.5.31).

Changes
- Resolve standard planes by geometry and origin by its native feature.
- Accept an already coincident endpoint only when native identity proves it.
- Verify sketch entry/exit through typed COM; reacquire the owned sketch after
  EditRebuild3 exits edit mode. Check ISketch identity when GetFeature is absent.
- Use real graphics-window coordinates instead of stale FrameWidth/FrameHeight.
- Check actual solver status, the fully-defined-sketch system setting and native
  CheckFeatureUse before extrusion. Unknown solver/topology results fail.
- Distinguish bounding-box containment from exact match, and reject unknown,
  non-finite or inverted bounds.
- Normalize native save results; a failed save prevents close/transaction commit.
- Close by full path and verify the target disappeared and other documents remain.
  Detect already-open paths and same-filename conflicts explicitly.
- Transaction rollback verifies native dimensions, geometry and document identity.
  Checkpoints never silently replace or overwrite the original document.
  Keep source/open documents during retention. Reject rollback plans for states
  the current snapshot cannot verify, including appearance/visibility changes.
- Rollback plans with equation-bearing sketch creation or batch dimension edits
  are rejected before mutation: live SW2025 sketch lifecycle calls invalidated
  native grouped undo. Explicit leave_partial does not promise an automatic undo.
